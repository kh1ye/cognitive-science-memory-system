# 当前生活化例子的口径

当前 examples-v3 依据用户希望的表达方式编写：例如“法国的首都是巴黎”展示语义知识，“我今天去看了电影”展示情景经历。每类25条，都是项目自建例子，并非论文原题。

- 工作记忆：在当前任务中暂时保持、处理的信息。
- 情景记忆：可以回忆的、亲自经历过的一件事。
- 语义记忆：关于世界、自己或他人的事实与知识。
- 程序性记忆：已经学会、能实施的技能。本稿用骑车、游泳、系鞋带等人的技能来帮助理解。

[CoALA §4.1](https://arxiv.org/html/2309.02427v3) 在智能体层面讨论运行状态、经历、知识与行为实现。本文的日常类比不意味着智能体已安装对应物理技能；“我会骑车”的文字本身也不等于可执行代码。智能体可以把这句话作为关于用户能力的语义事实保存。

所以，当前100条适合阅读和讨论四种记忆的区别；若用于评测真实输入分流，需要另外明确“描述谁的记忆、输入来自哪里、要存成什么对象”，不能直接把人的技能描述当成系统程序注册。
