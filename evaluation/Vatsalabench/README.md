# Vatsalabench 数据集与实验记录

这里收录本地加入的500条数据、六维指标定义，以及本项目的评测代码说明和逐轮记录。

- [数据集说明](数据集说明.md)：目录、历史、分支、题目和评分材料的用途。
- [六维指标原文](docs/VatsalaBench_六维指标.docx)：8项质量指标与3项效率指标，不合并总分。
- [运行方法](TESTING.md)：数据检查、单样本及批量测试。
- [实验记录索引](results/README.md)：已保存的各轮报告、原始回答和评分。

`dataset500_handoff_20261022_v1/` 是交付数据。原始的provenance、VALIDATION和README说明交付时状态，不代表所有题目已通过独立审核，也不是本项目的实验成绩。

本次Git入库副本有一项脱敏：`gpt4_7a0daae1`历史中的3处同一疑似GitHub访问令牌改为占位符，受影响的suite和清单哈希已更新，详见交付根目录的`LOCAL_SANITIZATION.json`。本地原件存放在Git忽略的`local-originals/`，不随仓库分发。没有更改问题、分支、gold或本轮已测试样本。

源数据和已归档结果通过`.gitattributes`禁用换行转换，以保留文件字节和校验值。`private/`是评分材料，不能导入被测记忆库或提供给被测回答模型。

每次测试默认在`results/<类型>-<时间戳>/`下新建独立目录；批次内每条样本再建子目录。提交输入文件哈希、配置、提取分析、原始回答、检索证据、裁判输出、人工复核、指标和失败日志。运行时SQLite库及备份仅本地保留，不纳入Git。显式指定已存在的输出目录会拒绝覆盖；继续中断运行需使用`--resume`。
