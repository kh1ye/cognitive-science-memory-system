# 结论：模型存在边界混淆，题目与提示也有影响

使用当前MiniMax-M3[1m]完成102次独立调用，无调用或格式失败。此次诊断不修改natural-v2的原始样本、标签和94/100记录，不以改提示后的成绩替代原成绩。

这不是另一家模型的盲测，也没有独立专家金标准；不能用来判断MiniMax相对其他供应商的优劣。

## 如何判断是不是模型的问题

按本项目概念评测约定，N063、N064、N073的结果支持一种具体诊断：当前模型在原提示下容易根据“流程、步骤”的内容归成程序性，而没有充分区分句子是在陈述知识，还是在展示已掌握的技能。语序改写并未消除这一模式，因此它不仅是偶发采样问题。

补充边界后这三句从0/9变为8/9符合参考，说明同一模型能在更明确的判据下大多作出目标区分。因此，证据同时指向提示口径不足和模型对该边界的敏感性，不能说模型完全不理解四种记忆。N064仍有一次不符合，不能宣称问题已经解决。

N058则需要承认原标注有争议。句子里没有感官细节，并不足以排除情景解释；相反，“第一次”明确提供了某次经历的指向。应把它作为待裁决边界例，而不是自动算模型错误。

原提示与补充提示都保持8条对照句24/24一致，说明本轮没有出现把所有问题都改答成语义的简单偏置。但对照很少，且选自已知答对样本，这不足以证明无其他回归。

## 判据依据与限制

个人语义知识与某次事件回忆的区分，可参见[Tanguay等的原始研究](https://elifesciences.org/articles/83645)；该研究也说明个人语义内容的边界并不简单。[NIMH定义](https://www.nimh.nih.gov/research/research-funded-by-nimh/rdoc/constructs/declarative-memory)同样区分事件表征与事实知识。技能表现与陈述性记忆的分离有[Cohen与Squire的实验](https://pubmed.ncbi.nlm.nih.gov/7414331/)作为依据。

上述文献支持区分维度，不是对这六句中文的直接标注。本报告对具体句子的判断属于本次审阅者的解释，没有独立专家裁决。

此次补充提示和改写都是看到错误后的干预。14/18是已知争议题上的结果，不是新的通用准确率，也不能推算成100条测试提高到多少分。原来的94/100保留。未更改项目生产提示，未验证实际存储分流或程序执行。
