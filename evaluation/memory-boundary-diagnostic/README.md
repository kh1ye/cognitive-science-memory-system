# 六条分类分歧的定向诊断

目标是检查原来6条分歧是否稳定、是否随语序与分类判据变化，不修改natural-v2的数据或原来的94/100。

首次诊断已完成102次调用：[结果解读](results/20261027-231131/interpretation.md)、[全部分布](results/20261027-231131/report.md)。6条争议句原提示2/18与参考一致，语序改写5/18，补充判据14/18；对照两种提示均24/24一致。属于事后诊断，不计为新的通用性能成绩。

实验在读取本轮结果前固定：

- 原句、原提示各重复3次：6条分歧与8条对照，共42次。
- 6条分歧作自然语序改写，原提示各3次，共18次。
- 原句加补充判据各3次：6条分歧与8条对照，共42次。

共102次独立调用，使用当前配置的同一模型，随机打乱交错执行，四路并发。对照取自之前答对的样本，每类2条，非新留出集。

模型看不到编号、参考标签或评分信息。补充判据是事后针对已知边界设计，强调陈述步骤与实际技能、个人背景与具体经历的区分。这是提示干预，不能用其结果声称模型在新问题上的准确率提高。

[参考标签审阅](reference-audit.json)在读取本轮预测前保存。尤其N058“我第一次学游泳是在小学”可以指具体的第一次经历，也可以只是在说明个人背景，不能把预设的语义标签当作唯一正确答案。

每次结果位于results/时间戳/，含调用前固定的plan.json、两种提示、哈希、全部预测、统计与报告。每条一次模型调用，SDK可能重试传输；不按答案好坏重问。

依据与适用范围：

- [NIMH陈述性记忆定义](https://www.nimh.nih.gov/research/research-funded-by-nimh/rdoc/constructs/declarative-memory)：区分事件表征与事实知识。
- [Tanguay等，2023，原始研究](https://elifesciences.org/articles/83645)：实验区分自传事实、重复事件与独特事件，也指出个人语义内容处在复杂边界上。
- [Cohen与Squire，1980，原始研究](https://pubmed.ncbi.nlm.nih.gov/7414331/)：技能学习与陈述性记忆可分离；不能把会复述步骤直接等同于实际技能表现。

这些研究支持本次采用的区分维度，没有直接标注这六条中文句子。本次审阅不是独立专家裁决，也不是对两个供应商模型的比较；未测试实际记忆系统分流、写入或程序执行。
