# 四种记忆：100条生活化进阶对照例子

按句子重点展示的认知过程给参考标签；现实活动可涉及多种记忆。这是作者标注的概念集，不是经过独立专家验证的金标准，也不是实际系统能力验收。

难度来自相同主题里的认知过程差异，不靠生僻知识。每组四条只是供人审阅，测试时会打乱顺序，隐藏分组、标签和解释。

参考标签在模型测试前确定；不根据模型答案修改标签。若模型与参考不一致，需要检查句子是否存在合理歧义。
