# 四种记忆生活化进阶对照集

[阅读全部100条及参考标签](review.md)，或使用 [JSON](cases.json)。基础集和已有测试结果均保留。

这批例子继续使用日常语言，难度主要来自同主题对照：同样说折纸，可以是在保持新看到的折法、回忆某次折纸、知道步骤但不会折，或直接执行已经练过的折纸动作。25个主题，每类25条。

额外加入没有日期的具体事件、有时间词的固定安排、步骤知识与实际技能的区分，以及夹有背景信息的当前任务。不是每条都含有上述干扰，也不宣称每条都比基础集更难。

参考标签在测试前确定，按句子重点展示的认知过程标注。真实活动可以涉及多类记忆；这些是作者给出的参考标签，未经独立专家验证。若预测不一致，应同时审阅模型理由和样本歧义，不应直接认定模型错了。

运行方式（项目根目录）：

```sh
.venv/bin/python evaluation/project-memory-100/run_concept_eval.py --dataset evaluation/project-memory-challenge-100/cases.json
```

沿用基础集的分类提示、模型配置、随机种子和四路并发。每条独立调用，模型只收到定义和当前例子，不收到编号、主题、同组例子、标签或参考依据。测试前的数据及提示哈希见 [frozen-manifest.json](frozen-manifest.json)。

结果保存于本目录的 `results/时间戳/`，`results/latest.json` 指向最近一次运行。每次完整保留逐条预测、简短依据、统计和提示；不根据分数重问、改参考答案或挑选结果。

首次实测使用 MiniMax-M3[1m]，97/100与参考标签一致：[完整结果](results/20261027-225651/report.md)。3条分歧都有“保留一种记忆、缺失另一种记忆”的双重焦点，见[分歧复核说明](results/20261027-225651/disagreement-review.md)。未经独立专家裁决，不应把3条全部认定为模型概念错误。

这是独立的概念识别测试；不测生产系统写入分流、工作状态管理或程序注册执行。
