## 模型配置

使用现有配置向同一 MiniMax 服务查询模型列表，服务返回有效 ID `MiniMax-M3`。原 `MiniMax-M3[1m]` 不在列表中，也被实际调用明确拒绝。

将本地 `.env` 的 `LLM_MODEL` 改为已验证的 `MiniMax-M3`，其余配置保留。直接调用成功返回 OK；重启服务后实际网页回答“你平时喜欢喝乌龙茶”，并展示原记忆引用。

## 来源回溯

- 手动记忆保留缺失的 thread/message，不再补出 `manual` 会话或把证据事件 ID 当消息 ID。
- 读取已完成首次 v2 迁移的来源时，优先使用原证据关系中的真实 thread/message 字段；不用重写旧记忆正文。
- 新聊天的 Observation 显式携带真实 `message_id`，并沿用到来源、策略证据和详情返回。
- 普通任务观察、程序来源不生成聊天链接。只有会话标识的旧来源继续提供会话链接，缺少消息 ID 时不伪造消息定位。
- 对真实名称恰好为 `manual` 的已知会话仍保留来源，不按字符串一刀切隐藏。
