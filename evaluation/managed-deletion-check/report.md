# 统一记忆删除验证

旧兼容记录原本 can_delete=true，新架构对象为 false，因此界面有的显示删除按钮、有的不显示。现已统一为可删除，并补齐后端删除处理。

- 覆盖工作状态、情景事件、语义断言、语义文档、程序版本与旧兼容记录。
- 单条删除清理检索激活引用和关联边，保留共享来源、兄弟记忆、对话记录；不是来源级级联删除。
- 学习回执清空已删除目标并保留操作身份，原来源重试不重建已删记忆。
- 程序版本解除活动版本指针、清理对应运行缓存；新版本号不复用已删版本号。
- 记忆管理、星图共用目录，展开的专属字段列表也在目录更新时刷新。
- 后端136项：135通过、1跳过；前端52项通过，生产构建通过。新增后端回归验证全部模块删除、用户空间隔离、重复删除404、统计更新、共享来源保护、重试与程序版本安全。
- 浏览器核对当前用户15条记录均支持删除，原生晨跑偏好详情有删除按钮；没有删除任何现有用户数据。截图 native-delete-action.png。
