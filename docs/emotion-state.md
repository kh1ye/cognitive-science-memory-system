# 个人助手：自动情绪与 Emoji

情绪是对当前表达的短时判断，不是用户的长期性格、诊断或 UserProfile 条目。没有用户手动选择情绪的入口。

## 识别与展示

支持 energetic ⚡、happy 😄、calm 😌、neutral 😐、tired 😴、sad 😔、anxious 😟、irritable 😤。

`ObservationAnalysis.emotion` 的模型输出包含 label、confidence、is_user_state、evidence_text。系统要求有本轮原文证据，且模型判断属于用户本人当前真实状态、置信度至少 0.75，才接受切换。不根据关键词直接匹配；提示词明确排除引用、翻译、假设、否定、讨论他人和历史情绪的错误归属。原文验证用于阻止无依据输出，无法保证模型永远不会误解语义。

不足阈值或识别失败时，保持该用户/会话/任务尚未过期的状态。默认有效期 300 秒，只有新的明确判断才刷新有效期；不确定判断不会延长旧状态。过期恢复 neutral，前端按后端返回的剩余时间自动恢复。新会话和服务重启从默认表情开始；运行期间刷新页面或返回原会话可读取尚未过期的内存状态。

## 调用与回答

`_observe` 复用既有 `analyze_observation` 调用，一次结构化输出同时返回记忆候选和情绪。关闭自动记忆、禁止本轮长期保存或纯聊天时，使用较小的情绪专用 schema 和提示词；仍使用同一个模型和分析函数，不会提取或提交长期候选。相对于过去完全跳过观察分析的轮次，会增加一次必要的情绪分析请求；正常需要记忆提取的轮次不增加独立情绪请求。

提供最近最多四条、合计不超过 2,000 字符的会话上下文用于消歧，历史不得作为本轮新记忆或情绪的原文证据。沿用现有一次 JSON 结构修复机制，失败不会中断正常回答。

回答的系统上下文包含 current_emotion，用于适度调整表达：疲惫时简洁、低落时温和、焦虑时条理清晰。明确的用户要求与事实准确性优先，不宣称确定知道用户内心，也不作心理诊断。

## 状态与隐私

- 情绪只在进程内的有界缓存（最多 1,024 个用户/会话/任务组合）和本轮 `ConversationState` 中流转，不增加数据库表。
- `ObservationAnalysis.emotion` 出现在提取 schema 中，但默认从 model_dump/model_dump_json 排除，避免进入记忆操作、学习回执和工作状态。
- LangGraph 使用 UntrackedValue 情绪通道；会话 Saver 同时排除 pending writes 和快照里的情绪字段。不能只依靠快照“不追踪”，因为中间写入也会存储节点输出。
- 不将实时情绪加入消息 additional_kwargs、持久化会话记录、用户画像或浏览器 localStorage。会话读取接口可返回内存中尚未过期的 current_emotion；前端将它提取到独立临时映射，不放进保存的聊天对象，并设置到期定时器。
- 关闭 auto_remember 仍识别情绪，但不保存本轮长期记忆；普通会话正文仍遵循原有保存设置。
- no_persist 不读取或更新进程内已有情绪，不保存检查点、会话或长期记忆，本次情绪只随响应返回。
- 删除会话及关闭服务清理对应进程内状态。不同用户、会话、任务互相隔离。
- 提示词禁止把临时情绪保存为语义事实，并拦截已知的临时心情主题候选。原有 Current/Candidate/History 规则不变。

## API 与前端

`POST /api/chat` 在原响应上增加：

```json
{"emotion":{"label":"happy","confidence":0.92,"emoji":"😄","ttl_seconds":300}}
```

普通会话读取接口可通过 `current_emotion` 返回进程内尚未过期的实时状态，但不会从持久化历史重建它。版本控制的示例对话可额外返回 `example_emotion` 静态回放标注，仅供显示该示例最后一轮的表情；继续真实聊天时清除回放标注，沿用实时状态和过期规则。剩余时间表示本次实时判断的有效期，不是长期属性。

个人助手聊天标题旁自动展示 Emoji 和简短状态，切换有轻微淡入、位移动画，遵循 prefers-reduced-motion。窄屏只显示表情，保留可访问标签。前端按固定映射展示 Emoji，不直接渲染任意服务端字符串。

## 验证

`tests/test_emotions.py` 覆盖八种状态映射、置信度/原文/归属门槛、提示词对错误归属的约束、过期、失败降级、关闭自动记忆、用户/会话/任务隔离、无持久化写入、重启、API 和上下文调用数。

前端 workspace 测试覆盖自动切换、默认与过期恢复、临时状态不写 localStorage、会话与用户隔离、八种固定 Emoji 映射和非法标签回退。离线测试使用确定性模型，不能等同于真实模型的情绪分类准确率评测。
