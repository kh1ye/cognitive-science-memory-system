# 记忆展示与对话工作记忆

## 长期记忆星图

导航：记忆管理下方 → 记忆展示；路由 `/#/memory-gallery`。

星图从现有 `/api/memories?view=all` 读取，只展示情景、语义、程序三类长期记忆。工作记忆属于当前任务上下文，不进入星图。支持类型筛选、文字搜索、点击／键盘打开节点、拖动旋转、滚轮与按钮缩放、自动旋转及重置视角。点击节点在当前视口居中弹出详情，不再占据侧栏或展开到星图下方。弹窗固定尺寸并锁定背景滚动，长字段在弹窗内部滚动；关闭按钮、Escape 或遮罩可关闭，恢复原位置和节点焦点。弹窗打开时暂停星图自动旋转。

点击节点后读取原始存储对象，逐项展示实际字段及其值。原生对象使用 `/api/architecture/objects/{module}/{object_id}`，兼容记录使用 `/api/memories/{id}`；两个接口均按用户空间读取。详情不再添加统一投影生成的状态、更新时间、来源、证据数量摘要。

星图与记忆管理共用当前用户空间和 `state.memories` 数据，不再单独读取演示空间。新增、删除、保留度检查、对话提取及架构面板写入成功后刷新共享目录；进入两个页面或重新聚焦标签页时同步服务端记录。全局切换用户空间同时影响两页。独立测试空间 `memory-gallery-demo` 保留36条长期记忆样例（情景／语义／程序各12条），需要查看时通过侧栏切换用户空间，不会混入当前用户。背景星点只做视觉装饰，节点数对应真实已加载的长期记录，查询上限1000条。连线表示类型分组，不代表已验证的语义或因果关系。

样例导入：先启动服务，再执行 `.venv/bin/python scripts/seed_memory_gallery.py`。脚本不清库，可重复执行。演示空间另外保留9条任务工作状态，不在星图展示；当前总计45条对象，36条为可见长期记忆。情景／语义通过 observe 生成真实记录；程序类使用兼容表保存人类技能样例，不注册为可执行程序。全部样例保存在独立演示空间。

## 对话工作记忆

个人助手 `/#/assistant` 增加工作记忆面板：桌面端位于对话右侧，窄屏位于对话下方。展示当前目标 `goals`、临时约束 `constraints`、待确认问题 `open_questions`，可展开查看完整工作状态原始字段。

面板使用后端实际任务工作状态，每轮回复完成后更新。会话接口返回对应任务的工作状态，切换或恢复会话时展示相应内容；新建会话清空面板旧值。空字段显示占位说明，不生成虚构目标。它与长期记忆星图使用不同展示位置。

## 验证

前端51项测试通过并完成生产构建；后端128项测试中127项通过、1项跳过。覆盖原始字段、用户空间隔离、会话恢复、任务 ID、目标与约束展示、新会话清空，以及星图筛选搜索和错误处理。

浏览器使用独立测试用户验证真实模型返回的读书计划目标、三项要点约束，以及新会话清空；完成后恢复 `demo-user`。截图和记录位于 `evaluation/memory-gallery-check/`。

## 统一删除

记忆管理中的新架构对象和旧兼容记录都支持删除，使用统一 `/api/memories/{id}` 接口。删除后刷新共享目录，星图和展开的架构列表同步更新；检索激活引用、关联边同时清理。单条记忆删除不会删除共享来源下的其他记忆或对话记录。学习回执保留删除标记，重放同一来源不会重新生成已删除的记忆。程序版本删除后解除活动指针，清理运行缓存，并保留版本号以避免重用。
